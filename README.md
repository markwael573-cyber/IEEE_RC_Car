# 🏎️ Turbo Cup — ESP32 RC Car & Mobile Control System

A connected **RC car system** built for the **Turbo Cup** competition organized by **IEEE BUB Student Branch**.

The project combines an **ESP32-powered RC car**, **Firebase**, and a **Flutter mobile application** to create a remotely controlled car connected through the cloud. After building the system, teams competed in a **Rocket League-inspired tournament**, where the cars were used to play a car-based football game.

## 🚀 Project Overview

Our team developed an RC car controlled through a custom Flutter mobile application.

The overall system works by:

1. 📱 The **Flutter mobile app** sends control commands.
2. ☁️ Commands are communicated through **Firebase**.
3. 🤖 The **ESP32** receives the commands and controls the RC car.
4. 🏎️ The car moves according to the player's input.
5. ⚽ The completed cars are used in a **Rocket League-style tournament**.

This project required integrating **embedded systems, cloud communication, and mobile application development** into a single working system.

## 🛠️ Technologies Used

* **ESP32** — Microcontroller and main control unit for the RC car
* **Firebase** — Cloud backend for communication between the mobile application and the car
* **Flutter / Dart** — Mobile application used to control the RC car
* **Embedded C/C++** — ESP32 programming and hardware control
